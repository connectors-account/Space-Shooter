# Scene Setup Instructions

These scenes need to be created in Unity Editor since Unity scene files (.unity)
require specific binary/YAML formatting that must be generated by the editor.

## Scene 1: MainMenu
1. File > New Scene
2. Save as `Assets/Scenes/MainMenu.unity`
3. Create an empty GameObject named `MainMenuSetup`
4. Attach the `MainMenuSetup.cs` script to it
5. The script will automatically create all UI elements at runtime

## Scene 2: GameScene
1. File > New Scene  
2. Save as `Assets/Scenes/GameScene.unity`
3. Create an empty GameObject named `GameSceneSetup`
4. Attach the `GameSceneSetup.cs` script to it
5. The script will automatically create: Player, Enemies, UI, Background, Managers

## Build Settings
1. File > Build Settings
2. Add scenes in order:
   - MainMenu (index 0)
   - GameScene (index 1)
3. Platform: PC, Mac & Linux Standalone
4. Target Platform: Windows
5. Click Build
