## 🎮 Game Features

### Core Gameplay
- **Player spaceship** with smooth WASD/Arrow key movement and Space to shoot
- **Health system** with 5 hit points and invincibility frames after damage
- **Wave-based enemy progression** with increasing difficulty
- **3 enemy types** with unique behaviors:
  - **Drone** — Fast, low health, sine-wave movement
  - **Fighter** — Medium health, zigzag movement, aimed shots at player
  - **Bomber** — High health, hovers and drifts, fires spread shots
- **Power-up system** with 3 types:
  - 🟡 **Rapid Fire** — Greatly increases fire rate for 6 seconds
  - 🔵 **Shield** — Absorbs one hit for 8 seconds
  - 🟢 **Health Restore** — Restores 2 health points
- **Collision detection** using Unity's 2D physics (Rigidbody2D, Collider2D triggers)
- **Explosion visual effects** with animated expanding rings
- **Parallax starfield background** with 3 scrolling layers

### UI System
- **Main Menu** — Start Game, Quit, animated title, control hints
- **In-Game HUD** — Score display, wave counter, health indicator
- **Pause Menu** (Escape key) — Resume, Main Menu buttons
- **Game Over Screen** — Final score, Play Again, Main Menu buttons

## 🔧 Setup Instructions

### Step 1: Install Unity

1. Download **Unity Hub** from https://unity.com/download
2. Install Unity Hub and sign in with a Unity account (free Personal license)
3. In Unity Hub, go to **Installs** → **Install Editor**
4. Choose **Unity 2022.3 LTS** (or newer)
5. In the modules selection, ensure **Windows Build Support (IL2CPP)** is checked
6. Click Install and wait for completion

### Step 2: Open the Project

1. Open **Unity Hub**
2. Click **Open** → **Add project from disk**
3. Navigate to the `SpaceShooterGame` folder and select it
4. Unity will import the project (this may take a few minutes on first open)
5. If prompted about a Unity version mismatch, click **Continue** to upgrade

### Step 3: Auto-Build the Scenes

The project includes an automated scene builder that creates all GameObjects, prefabs, and scene configurations:

1. Once Unity finishes importing, go to the top menu bar
2. Click **Tools** → **Space Shooter** → **Setup Tags**
   - This creates the required tags (PlayerBullet, EnemyBullet, Enemy, PowerUp)
3. Click **Tools** → **Space Shooter** → **Build All Scenes**
   - This automatically creates:
     - All sprite assets in `Assets/Sprites/`
     - All prefabs in `Assets/Prefabs/`
     - The `MainMenu` scene with full UI
     - The `GameScene` with player, enemies, spawners, UI, and background
     - Build Settings configured with both scenes

### Step 4: Play the Game

1. In the **Project** window, navigate to `Assets/Scenes/`
2. Double-click **MainMenu** to open the main menu scene
3. Press the **Play** button (▶) at the top of the Unity Editor
4. Click **START GAME** to begin playing!

## 🏗️ Building for Windows

### Quick Build

1. Go to **File** → **Build Settings**
2. Verify both scenes are listed:
   - `Scenes/MainMenu` (index 0)
   - `Scenes/GameScene` (index 1)
3. Set **Platform** to **Windows, Mac, Linux** (should be default)
4. Set **Target Platform** to **Windows**
5. Set **Architecture** to **x86_64**
6. Click **Build**
7. Choose an output folder (e.g., `Build/`)
8. Wait for the build to complete
9. Run the generated `.exe` file!

### Release Build (Optimized)

1. In Build Settings, click **Player Settings**
2. Under **Resolution and Presentation**:
   - Set **Fullscreen Mode** to "Windowed" or "Fullscreen Window"
   - Set **Default Screen Width** to 1024
   - Set **Default Screen Height** to 768
3. Under **Other Settings**:
   - Set **Scripting Backend** to **IL2CPP** for best performance
4. Back in Build Settings, check **Development Build** OFF
5. Click **Build** and select your output folder

## ⚙️ Game Mechanics

### Wave Progression
- **Wave 1-2**: Only Drones (easy enemies)
- **Wave 3-4**: Drones + Fighters (aimed shots)
- **Wave 5+**: All three types including Bombers (spread shots)
- Each wave increases enemy count by 2
- Spawn rate increases with each wave

### Enemy Types

| Enemy   | Health | Score | Movement              | Attack            |
|---------|--------|-------|-----------------------|-------------------|
| Drone   | 1      | 50    | Straight + sine wave  | Single shots down |
| Fighter | 3      | 150   | Zigzag descent        | Aimed at player   |
| Bomber  | 8      | 300   | Descend then hover    | 3-way spread shot |

### Power-Up Drop Rates
- Drones: 10% chance
- Fighters: 25% chance
- Bombers: 50% chance

### Power-Up Distribution
- Rapid Fire: 40% of drops
- Shield: 30% of drops
- Health Restore: 30% of drops

## 🔊 Adding Custom Audio

The game has audio support built in but ships without audio files to keep the project lightweight. Here's how to add sounds:

### Sound Effects

1. Place `.wav` or `.ogg` files in `Assets/Audio/`
2. Recommended sound effects to add:
   - `player_shoot.wav` — Player bullet fire
   - `enemy_shoot.wav` — Enemy bullet fire
   - `explosion.wav` — Enemy/player destruction
   - `hit.wav` — Player taking damage
   - `death.wav` — Player death
   - `powerup_pickup.wav` — Collecting a power-up
3. In Unity, select the **Player** GameObject in the GameScene
4. In the **PlayerController** component, drag audio files to the corresponding slots:
   - `Shoot Sound` → player_shoot.wav
   - `Hit Sound` → hit.wav
   - `Death Sound` → death.wav
5. For enemy prefabs (in `Assets/Prefabs/`):
   - Select each enemy prefab
   - Drag `enemy_shoot.wav` to **Shoot Sound**
   - Drag `explosion.wav` to **Death Sound**
6. For power-ups:
   - Select each PowerUp prefab
   - Drag `powerup_pickup.wav` to **Pickup Sound**

### Background Music

1. Place `.mp3` or `.ogg` music files in `Assets/Audio/`
2. Select the **AudioManager** GameObject in the scene
3. Drag music files to:
   - `Menu Music` → your menu background track
   - `Game Music` → your gameplay background track

### Free Sound Resources
- **Freesound.org** — Free sound effects (CC licensed)
- **OpenGameArt.org** — Free game audio assets
- **Kenney.nl** — Free game assets including sounds

## 🎨 Customization Guide

### Adjusting Difficulty
Select the **EnemySpawner** in the GameScene hierarchy:
- `Base Enemies Per Wave` — Starting enemy count (default: 5)
- `Enemies Increase Per Wave` — Additional enemies each wave (default: 2)
- `Time Between Spawns` — Delay between spawns (default: 1.5s)
- `Time Between Waves` — Rest period between waves (default: 4s)

### Adjusting Player
Select the **Player** GameObject:
- `Move Speed` — Player movement speed (default: 8)
- `Fire Rate` — Seconds between shots (default: 0.3)
- `Max Health` — Starting health points (default: 5)
- `Invincibility Duration` — Post-hit invincibility (default: 2s)

### Adjusting Power-Ups
Select the **PowerUpSpawner** GameObject:
- `Rapid Fire Weight` — Chance of rapid fire drop
- `Shield Weight` — Chance of shield drop
- `Health Weight` — Chance of health restore drop

### Replacing Sprites
1. Place your custom `.png` sprites in `Assets/Sprites/`
2. Select the sprite in Unity, set **Sprite Mode** to **Single**
3. Set **Pixels Per Unit** to match your sprite size (32 for 32x32 sprites)
4. Drag onto the corresponding prefab's **Sprite Renderer** component

## 🐛 Troubleshooting

### "Tag not found" errors
- Run **Tools** → **Space Shooter** → **Setup Tags** again
- Or manually add tags in **Edit** → **Project Settings** → **Tags and Layers**

### Scenes not loading
- Check **File** → **Build Settings** has both scenes listed
- MainMenu should be at index 0, GameScene at index 1
- If missing, drag scenes from `Assets/Scenes/` into the Build Settings list

### Objects not colliding
- Ensure all objects have **Collider2D** components set to **Is Trigger = true**
- Ensure objects have correct tags (Player, PlayerBullet, EnemyBullet, Enemy)
- Check that **Rigidbody2D** gravity is set to 0

### Unity version warnings
- The project targets Unity 2022.3 LTS
- If using a newer version, click "Continue" when prompted to upgrade
- All APIs used are stable and available in Unity 2022.3+
