# 🚀 Space Shooter - Unity Game

A simple but complete space-shooter game built with Unity, using only built-in primitive shapes (cubes and spheres). No external assets required!

## 🎮 Game Features

- **Player Ship** — Move with WASD/Arrow keys, shoot with Space/Left-Click
- **Enemy Waves** — Enemies spawn from above and track toward the player
- **Scoring System** — Earn points for destroying enemies
- **Health System** — Player has 100 HP; enemies deal 20 damage on contact
- **Power-Ups** — Green health pickups occasionally spawn to restore 30 HP
- **Difficulty Ramp** — Enemies spawn faster over time
- **Game Over Screen** — Shows final score with restart option (press R)

## 🛠️ Setup Instructions

### Prerequisites
- **Unity 2021.3 LTS** or newer (any recent Unity version works)
- **Windows** for building a Windows executable

### Step 1: Open the Project
1. Open **Unity Hub**
2. Click **"Open"** (or "Add project from disk")
3. Navigate to and select the `space_shooter_unity` folder
4. Unity will import the project (this may take a minute)

### Step 2: Set Up Tags (IMPORTANT — do this first!)
1. Go to **Edit → Project Settings → Tags and Layers**
2. Make sure these **Tags** exist (add them if they don't):
   - `Player` (usually built-in)
   - `Enemy`
   - `PowerUp`
3. Close Project Settings

### Step 3: Auto-Setup the Scene (Recommended)
The project includes an editor wizard that builds the entire scene automatically:

1. In the Unity menu bar, click **Tools → Space Shooter → Setup Entire Scene**
2. This will create:
   - Player ship (blue cube) with all scripts attached
   - Enemy, Bullet, and PowerUp prefabs in Assets/Prefabs
   - Colored materials in Assets/Materials
   - Game Manager and Enemy Spawner
   - Full UI Canvas (score, health bar, game over panel)
   - Proper camera setup (orthographic, dark background)
3. **Save the scene**: `Ctrl+S` → save as `Assets/Scenes/MainScene.unity`

### Step 3 (Alternative): Manual Scene Setup
If you prefer to set up manually, see the **Manual Setup** section below.

### Step 4: Play Test
1. Press the **Play** button (▶) in Unity
2. Use **WASD** or **Arrow Keys** to move
3. Press **Space** or **Left-Click** to shoot
4. Destroy red enemies, collect green power-ups
5. When you die, press **R** to restart

### Step 5: Build for Windows
1. Go to **File → Build Settings**
2. Click **"Add Open Scenes"** to add MainScene
3. Select **"PC, Mac & Linux Standalone"** as the platform
4. Set **Target Platform** to **Windows**
5. Set **Architecture** to **x86_64**
6. Click **"Build"** or **"Build and Run"**
7. Choose an output folder (e.g., `Builds/`)
8. Unity will produce a `.exe` file — that's your game!

## 🔧 Manual Scene Setup (if not using the wizard)

If the auto-setup wizard doesn't work or you want to understand the setup:

### Create the Player
1. **GameObject → 3D Object → Cube** — name it `Player`
2. Set **Tag** to `Player`
3. Set **Position**: (0, -3.5, 0), **Scale**: (1, 0.3, 0.5)
4. Remove the default **Box Collider**, add a new one with **Is Trigger** ✓
5. Add **Rigidbody** → uncheck Use Gravity, check Is Kinematic
6. Create an empty child named `FirePoint` at local position (0, 1, 0)
7. Add scripts: **PlayerController** and **PlayerHealth**
8. In PlayerController, assign the `FirePoint` and `Bullet` prefab

### Create the Bullet Prefab
1. **GameObject → 3D Object → Sphere** — name it `Bullet`
2. Set **Scale**: (0.2, 0.4, 0.2)
3. Remove default collider, add **Sphere Collider** with **Is Trigger** ✓
4. Add **Rigidbody** → no gravity, kinematic
5. Add the **Bullet** script
6. Drag from Hierarchy into `Assets/Prefabs` to create prefab
7. Delete the instance from the scene

### Create the Enemy Prefab
1. **GameObject → 3D Object → Cube** — name it `Enemy`, tag it `Enemy`
2. Set **Scale**: (0.8, 0.8, 0.5)
3. Remove default collider, add **Box Collider** with **Is Trigger** ✓
4. Add **Rigidbody** → no gravity, kinematic
5. Add the **EnemyController** script
6. Drag into `Assets/Prefabs`, delete scene instance

### Create the PowerUp Prefab
1. **GameObject → 3D Object → Sphere** — name it `PowerUp`, tag it `PowerUp`
2. Set **Scale**: (0.5, 0.5, 0.5)
3. Remove default collider, add **Sphere Collider** with **Is Trigger** ✓
4. Add **Rigidbody** → no gravity, kinematic
5. Add the **PowerUp** script
6. Drag into `Assets/Prefabs`, delete scene instance

### Create Game Manager
1. Create an empty GameObject named `GameManager`
2. Add the **GameManager** script

### Create Enemy Spawner
1. Create an empty GameObject named `EnemySpawner`
2. Add the **EnemySpawner** script
3. Assign the Enemy and PowerUp prefabs in the Inspector

### Set Up Camera
1. Select **Main Camera**
2. Set **Projection** to **Orthographic**
3. Set **Size** to **5.5**
4. Set **Position** to (0, 0, -10)
5. Set **Background** color to dark blue/black

### Set Up UI
1. **GameObject → UI → Canvas** — this auto-creates EventSystem
2. Add these UI Text elements as children of Canvas:
   - `ScoreText` — anchor top-left, font size 20
   - `HealthText` — anchor top-right, font size 20
3. Create a health bar (Image → Filled, horizontal)
4. Create a `GameOverPanel` with title, final score, and restart text
5. Add **UIManager** script to Canvas and wire up all references

## 🎯 Controls

| Input | Action |
|-------|--------|
| WASD / Arrow Keys | Move player |
| Space / Left-Click | Shoot |
| R | Restart (when game over) |

## ⚙️ Tweakable Values (in Inspector)

| Script | Property | Default | Description |
|--------|----------|---------|-------------|
| PlayerController | moveSpeed | 8 | Player speed |
| PlayerController | fireRate | 0.2s | Seconds between shots |
| PlayerHealth | maxHealth | 100 | Starting health |
| EnemyController | moveSpeed | 3 | Enemy fall speed |
| EnemyController | trackingStrength | 1.5 | How much enemies home in |
| EnemySpawner | spawnInterval | 2s | Starting spawn rate |
| EnemySpawner | minSpawnInterval | 0.5s | Fastest spawn rate |
| EnemySpawner | powerUpChance | 8% | Chance of power-up spawn |
| PowerUp | healAmount | 30 | HP restored on pickup |
| Bullet | speed | 15 | Bullet travel speed |
