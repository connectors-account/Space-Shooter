# 🚀 Space Shooter

A complete, fully-featured 2D space shooter game built with Unity.

## Features
- 4 enemy types: Basic, Fast, Tank, and Boss
- Wave-based progression with procedural difficulty scaling
- 6 power-up types: Health, Shield, Rapid Fire, Spread Shot, Extra Life, Score Bonus
- Multiple bullet patterns: Straight, Spread, Circle, Aimed, Homing
- Parallax scrolling background with particle starfield
- Full UI: Main Menu, HUD, Pause Menu, Game Over screen
- High score persistence
- Sound system with SFX pooling and music support

## Controls
| Key | Action |
|---|---|
| WASD / Arrow Keys | Move |
| Space / Left Click | Fire |
| Escape | Pause / Resume |

## Quick Start
1. Open project in Unity 2021.3+
2. Run **Tools → Space Shooter → Full Game Setup**
3. Open `Assets/Scenes/MainMenu.unity`
4. Press Play!

See [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md) for full setup and build guide.
