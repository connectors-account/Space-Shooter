# 🚀 Space Shooter - Unity Desktop Game

A classic arcade-style space shooter game built with Unity and C#. Fight waves of enemies, collect power-ups, and chase high scores!

![Genre](https://img.shields.io/badge/genre-arcade_shooter-blue)
![Platform](https://img.shields.io/badge/platform-Windows-green)
![Engine](https://img.shields.io/badge/engine-Unity_2021.3+-orange)

---

## 🎮 Game Features

- **Player Ship** with smooth WASD/Arrow key movement and spacebar shooting
- **Wave-Based Enemy Spawning** with increasing difficulty across waves
- **4 Enemy Types**: Basic, Fast (zigzag), Tank (high HP, shoots), Shooter (sine wave, rapid fire)
- **3 Power-Up Types**: Weapon Upgrade (up to triple spread), Shield (absorbs one hit), Health Recovery
- **Weapon Upgrade System**: Level 1 (single), Level 2 (dual), Level 3 (triple spread)
- **Health System** with invincibility frames and visual feedback
- **Parallax Scrolling Background** with twinkling stars
- **Score System** with persistent high score (saved via PlayerPrefs)
- **Full UI**: HUD, Pause Menu (ESC), Game Over screen
- **Audio Manager** for sound effects (works with or without audio clips)

## 🚀 Quick Start (Fastest Method — Auto-Bootstrap)

This project includes an **AutoSceneSetup** script that creates the entire game scene programmatically at runtime. This is the fastest way to get the game running:

### Step 1: Install Unity
- Download [Unity Hub](https://unity.com/download)
- Install **Unity 2021.3 LTS** or newer (any 2021.3.x, 2022.x, or 2023.x version)
- Include the **Windows Build Support** module during installation

### Step 2: Open the Project
1. Open **Unity Hub**
2. Click **"Open" → "Add project from disk"**
3. Navigate to the `space_shooter_game` folder and select it
4. Unity will import the project (may take a few minutes on first open)

### Step 3: Set Up Tags (REQUIRED)
Before running, you must create the custom tags Unity needs:

1. Go to **Edit → Project Settings → Tags and Layers**
2. Under **Tags**, click **+** and add these tags:
   - `Player`
   - `Enemy`
   - `PlayerBullet`
   - `EnemyBullet`
   - `PowerUp`

### Step 4: Create the Game Scene
1. Go to **File → New Scene** (choose "Basic 2D" if prompted)
2. Save it as `Assets/Scenes/GameScene.unity`
3. In the **Hierarchy**, create an empty GameObject: **GameObject → Create Empty**
4. Name it `_Bootstrap`
5. In the Inspector, click **Add Component** → search for `AutoSceneSetup` → add it
6. Make sure **Auto Setup** is checked ✅
7. Press **Play** ▶️ — the entire game sets itself up automatically!

### Step 5: Create the Main Menu Scene (Optional)
1. **File → New Scene** → save as `Assets/Scenes/MainMenuScene.unity`
2. Add a **Canvas** (GameObject → UI → Canvas)
3. Add the `MainMenuController` script to the Canvas
4. Add UI elements:
   - **Text** for title: "SPACE SHOOTER"
   - **Text** for high score display
   - **Button** for "Start Game"
   - **Button** for "Quit"
5. Wire the Text and Button references in the Inspector
6. Add both scenes to **File → Build Settings → Scenes In Build**

## 🎨 Generating Placeholder Sprites

### Option A: Runtime Generation (Default)
The `RuntimeSpriteGenerator.cs` automatically creates colored geometric sprites when the game starts. **No sprite files needed.**

### Option B: Editor Tool (Persistent Files)
1. In Unity, go to menu: **Tools → Generate Placeholder Sprites**
2. This creates PNG files in `Assets/Sprites/`:
   - `PlayerShip.png` — Green triangle (pointing up)
   - `EnemyBasic.png` — Red triangle (pointing down)
   - `EnemyFast.png` — Orange diamond
   - `EnemyTank.png` — Dark red square
   - `EnemyShooter.png` — Purple triangle (pointing down)
   - `BulletPlayer.png` — Yellow thin rectangle
   - `BulletEnemy.png` — Red circle
   - `PowerUpWeapon.png` — Yellow square
   - `PowerUpShield.png` — Cyan circle
   - `PowerUpHealth.png` — Green cross
   - `Star.png` — Tiny white dot
   - `Background.png` — Dark blue tile

### Option C: Custom Sprites
Replace any of the above with your own 32x32 or 64x64 pixel art. Import as **Sprite (2D and UI)** with **Pixels Per Unit = 32**.

## 🔊 Adding Sound Effects

The game runs fine without audio, but you can add sounds:

1. Place `.wav` or `.mp3` files in `Assets/Audio/`
2. Select the **AudioManager** GameObject
3. In the Inspector, expand **Sound Effects** array
4. Add entries with these names (matching what the code calls):
   - `PlayerShoot` — player fires
   - `PlayerHit` — player takes damage
   - `PlayerDeath` — player dies
   - `EnemyShoot` — enemy fires
   - `EnemyDeath` — enemy destroyed
   - `PowerUp` — power-up collected
   - `ShieldBreak` — shield absorbed a hit
   - `WaveStart` — new wave begins
   - `GameOver` — game over triggered
5. Drag audio clips into each entry's **Clip** field

**Free SFX Sources:**
- [Freesound.org](https://freesound.org/)
- [OpenGameArt.org](https://opengameart.org/)
- [Kenney.nl/assets](https://kenney.nl/assets) (Game Assets)

## 🏗️ Building the Windows Executable

### Prerequisites
- Unity 2021.3+ with **Windows Build Support (Mono)** module installed
- (Check in Unity Hub → Installs → your version → Add Modules)

### Build Steps

1. **Open the project** in Unity

2. **Add scenes to build:**
   - Go to **File → Build Settings**
   - Click **Add Open Scenes** for each scene, or drag them in:
     - `Assets/Scenes/MainMenuScene.unity` (index 0 — loads first)
     - `Assets/Scenes/GameScene.unity` (index 1)
   - If only using GameScene with auto-bootstrap, just add that one

3. **Configure build target:**
   - In Build Settings, select **PC, Mac & Linux Standalone**
   - Set **Target Platform** to **Windows**
   - Set **Architecture** to **x86_64** (64-bit)

4. **Configure Player Settings:**
   - Click **Player Settings** button (or Edit → Project Settings → Player)
   - **Product Name**: "Space Shooter" (or your preferred name)
   - **Company Name**: Your name/studio
   - **Default Screen Width**: 1280
   - **Default Screen Height**: 720
   - **Fullscreen Mode**: Windowed (or Fullscreen Window)
   - **Resizable Window**: Unchecked (recommended for fixed aspect ratio)
   - **Run In Background**: Checked

5. **Build:**
   - Click **Build** (or **Build And Run** to test immediately)
   - Choose an output folder (e.g., `Builds/Windows/`)
   - Unity compiles everything into a Windows executable

6. **Output:**
   ```
   Builds/Windows/
   ├── Space Shooter.exe          ← Run this to play!
   ├── Space Shooter_Data/        ← Game data (must stay next to .exe)
   ├── UnityPlayer.dll            ← Unity runtime
   └── MonoBleedingEdge/          ← Mono runtime
   ```

7. **Distribute:**
   - Zip the entire output folder
   - Recipients just extract and run the `.exe`
   - No Unity installation required for players!

### Build Troubleshooting

| Issue | Solution |
|-------|----------|
| "No scenes in build" | Add scenes in File → Build Settings |
| Missing tags error | Set up tags in Edit → Project Settings → Tags and Layers |
| Pink/missing sprites | Use the auto-bootstrap scene (creates sprites at runtime) |
| Script compilation errors | Ensure Unity 2021.3+ and all modules installed |
| Build fails on IL2CPP | Switch to Mono backend in Player Settings → Other Settings |

## 🎯 Game Design Details

### Enemy Types and Waves

| Wave | Enemy Types Available | Notes |
|------|----------------------|-------|
| 1-2  | Basic only           | Learning phase |
| 3-4  | Basic + Fast         | Zigzag enemies added |
| 5-6  | Basic + Fast + Shooter | Enemies that shoot back |
| 7+   | All types + Tank     | Full difficulty, bullet sponges |

### Difficulty Scaling
- **Enemies per wave**: 3 + (wave - 1) × 2, capped at 20
- **Spawn interval**: Decreases by 0.05s per wave (min 0.3s)
- **Enemy speed**: Increases slightly each wave
- **Enemy HP**: Scales with wave number
- **Drop rate**: Increases slightly each wave

### Scoring
| Enemy Type | Points |
|-----------|--------|
| Basic     | 100    |
| Fast      | 150    |
| Shooter   | 200    |
| Tank      | 300    |

### Power-Ups
| Type | Color | Effect |
|------|-------|--------|
| Weapon Upgrade | Yellow | Upgrades weapon level (max 3) |
| Shield | Cyan | Absorbs one hit |
| Health | Green | Restores 2 HP |

## 🛠️ Customization

### Adjusting Difficulty
Edit `EnemySpawner.cs`:
- `timeBetweenWaves` — delay between waves (default: 3s)
- `spawnInterval` — time between enemy spawns (default: 1s)
- Modify `SpawnWave()` for custom enemy counts
- Modify `ConfigureEnemy()` for stat changes

### Adjusting Player
Edit `PlayerController.cs`:
- `moveSpeed` — player movement speed (default: 8)
- `fireRate` — time between shots (default: 0.25s)
- `maxHealth` — starting health (default: 5)
- `invincibilityDuration` — i-frames after hit (default: 1.5s)

### Adding New Enemy Types
1. Create a new prefab (or let the spawner create one)
2. Add a new case in `EnemySpawner.ChooseEnemyPrefab()`
3. Add configuration in `EnemySpawner.ConfigureEnemy()`
4. Use `EnemyController.MovementPattern` enum for movement
