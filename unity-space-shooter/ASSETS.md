### Asset provenance

All runtime media is shipped locally. There are no runtime downloads or external account dependencies. No branded characters or third-party game sprite packs are used.

| Asset | Origin and processing |
|---|---|
| `Assets/Art/OriginalAtlas.png` | Original AI-generated 2×2 sprite atlas made for this project: cyan player, red enemy, repair capsule, weapon capsule; generated using GPT Image 2.5. Original output retained. |
| `Assets/Art/Player.png`, `Enemy.png`, `Repair.png`, `Weapon.png` | Cropped from that atlas, faint alpha residue removed, centered to 256×256 transparent PNGs using `Tools/prepare_assets.py`. |
| `Assets/Art/Glow.png` | 64×64 mathematical radial light kernel for bullets, stars, and sparks, generated by the same tool; not a hand-drawn illustration. |
| `Assets/Audio/laser.mp3` | Original generated single arcade laser effect from ElevenLabs SFX, created for this project; original local file retained. |
| `Assets/Audio/EnemyShot.wav`, `Explosion.wav`, `Hit.wav`, `Pickup.wav`, `UI.wav`, `GameOver.wav`, `Wave.wav` | Original offline synthesized sound effects, deterministic seed 417, written as real mono 44.1 kHz 16-bit PCM WAV files by `Tools/prepare_assets.py`. |
| `Docs/SpritePreview.png` | Contact sheet of the four finished sprites on a dark background; not a screenshot of Unity gameplay. |
